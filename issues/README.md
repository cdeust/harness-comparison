# Public issue registry

This is the canonical public issue registry for the capstone. Issues are
organized by stack, category, and subject. Internal tracker references are
deliberately excluded from this public registry.

## Stacks

- `ai-architect/` — product maturity and sovereignty gaps.
- `external-solutions/` — open-source comparison and frontier findings.
- `shared-infrastructure/` — Claude/Codex setup, isolation, security,
  scalability, and reproducibility.

## Categories

`memory`, `orchestration`, `code-intelligence`, `provenance`, `observability`,
`security`, `scalability`, `finops`, `integration`, `documentation`.

Every issue must state symptom, subject, reproduction, evidence, sovereignty
impact, external acceptance test, status, and benchmark revision.
